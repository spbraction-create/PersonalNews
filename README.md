# README — מפת הדרכים לבניית סוכן הדייג'סט

מסמך זה הוא סדר הפעולות שלך מכאן. התכנון הסתיים; מכאן זו בנייה.
שני קבצי מקור-אמת מלווים אותך לאורך הדרך:
- **`EDITORIAL.md`** — כל ההיגיון העריכתי (טורים, סיווג, פרומפטים, תיוּר).
- **`SOURCES.md`** — רשימת המקורות ומנגנון הוספת מקור.

---

## מי עושה מה — הבהרה שתחסוך בלבול

- **Claude Code** = הקבלן. כותב את הקוד, פעם אחת. לא רץ כל יום. אתה עובד איתו מול הריפו.
- **Gemini** = החשמל. ה-brains שרץ בתוך הכלי כל בוקר, אוטומטית, לנצח. אתה לא "עובד מולו" — אתה רק מקים לו חשבון ומפתח פעם אחת.
- **GitHub Actions** = השעון. מעיר את הכלי ב-05:00.
- **Cloudflare (Worker + KV + Pages)** = הבית. מגיש את הגיליון ושומר מצב.

## שלב 0 — הקמת חשבונות (חד-פעמי, לפני קוד)

### מול Gemini (Google AI Studio)
1. היכנס ל-**aistudio.google.com** עם חשבון גוגל.
2. צור **API key**.
3. **אל תחבר כרטיס אשראי. אל תיגע ב-Vertex AI.** זו חומת המגן — בלי כרטיס אין במה לחייב.
4. שמור את המפתח למקום בטוח (ייכנס בהמשך כ-secret ב-GitHub).

> תזכורת: השכבה החינמית מספיקה בפער עצום (אלפי בקשות/יום מול בודדות בפועל). חריגה = בקשה חסומה, לא חיוב.

### חשבונות נוספים (אם עוד אין)
- **GitHub** — לריפו ול-Actions.
- **Cloudflare** — ל-Worker, KV ו-Pages. גם כאן: בלי כרטיס.

## שלב 2 — המשימה הראשונה: רכיב גילוי-הפיד (מול Claude Code)

זה הרכיב שגם מאמת את כל המקורות הקיימים וגם משמש כמנגנון הוספת מקור עתידי. שני דברים, קוד אחד.

בקש מ-Claude Code:
1. רכיב שמקבל **כתובת אתר** ומגלה את פיד ה-RSS שלו (חיפוש `<link rel="alternate" type="application/rss+xml">`, וניסיון `/feed` כברירת מחדל).
2. הרצה על כל הרשימה ב-`SOURCES.md` → דוח: אילו מקורות עובדים, אילו לא.
3. עדכון `SOURCES.md` עם כתובות הפיד שנמצאו.

**תוצר:** רשימת פידים מאומתת + הרכיב שיהפוך אחר כך למנגנון ההוספה.

## שלב 4 — שכבת העריכה (מול Claude Code, מפעיל את Gemini)

לפי `EDITORIAL.md`:
1. **סיווג** כל פריט: טור → ידיעה/עומק → אם עומק, מוסף/ירחון. (פרומפט הסיווג, מתודת הדולר.)
2. **בריף יומי** לכל טור: פרומפט הסינתזה (~200 מילה) + כרטיסי כותרת-תקציר-תמונה (מה-RSS, בלי AI).
3. **תור סופ״ש/חודשי**: פריטי העומק נשמרים ל-KV עד שישי / 1 בחודש.
4. **עריכה** בשערי המוסף/ירחון: פרומפט העורך הראשי (עד 10 הטובים).

> כל קריאות ה-AI כאן הן ל-Gemini. Claude Code רק *כותב* את הקוד שקורא ל-Gemini — הוא לא חלק מהריצה.

## עקרונות שלא משתנים (תזכיר לאורך הבנייה)

- **אפס עלות תפעול.** בלי כרטיס אשראי לאף חשבון. חריגת מכסה = בקשה חסומה, לא חיוב.
- **Gemini הוא ה-brains בריצה. Claude Code רק בונה.** הם לא מדברים זה עם זה.
- **מקורות האמת הם הקבצים.** שינוי עריכתי = עדכון `EDITORIAL.md`, לא תיקון נקודתי בקוד.
- **עורך, לא מכונת מדף.** טווח יעד 5–10 הטובים (יומי, מוסף וירחון כאחד) — איכות תמיד גוברת על מכסה.
- **לא להזרים מידע אישי ל-Gemini** (השכבה החינמית עשויה לאמן על הקלט). תוכן ציבורי בלבד.
